# **🚀 goSSMS v0.2.2**
Hide Object Explorer, smarter IntelliSense and safer command-line runs.

## ✨ New
- Hide and restore Object Explorer
- IntelliSense: user types, DDL, more built-ins
- Picture brightness and contrast
- CSV/TSV formula neutralization
- Stricter CLI write and parameter checks

## 🔧 Fixes
- Plan cost badges and columnstore scans
- Safer CLI output for control characters
- Windows file, lock and clipboard issues

## ⚡ Changes
- `gosmo` v0.4.0, `tuikit` v0.1.0

## 📦 Install or upgrade
```
brew install radix29/tap/gossms
```
