# **🚀 goSSMS v0.1.1**
Format Document, shrink dialogs and safer connections.

## ✨ New
- Format Document (SQL, JSON, XML), Execute at Cursor
- Light theme
- Shrink Database / Files
- Restore standby and point-in-time
- DML trigger toggle, index rebuild/reorganize/disable
- Column sorting in details and results
- Max fetch rows option

## 🔧 Fixes
- Certificates validated by default
- Peer credentials pinned to registered servers
- Last grid column stays visible
