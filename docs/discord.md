# **🚀 goSSMS v0.1.2**
Group by Schema, five new object dialogs and double-click navigation.

## ✨ New
- Group by Schema in Object Explorer (Alt+G)
- New Schema, Database Role, Application Role, Sequence, Synonym
- Double-click in Details navigates into the object
- Query Store wait-category drill-down

## 🔧 Fixes
- Disabled toolbar actions say why
- Create-dialog background actions recover from panics
