## F4 — Enter right after a fully typed catalog name commits it

**Where:** `internal/tui/completion_keywords.go` (`Soft` at ~146) and the
catalog-name candidate builders. `docs/open-threads.md` § Completion.

**What:** `FROM sys.tables⏎` leaves no newline: the popup holds the exact
match and Enter commits it. Keywords avoid this via `CompletionItem.Soft`;
catalog names do not.

**Plan (proposed decision):** mark a candidate `Soft` when the typed prefix
already equals its insert text (case-insensitive under the database
collation, `databaseCollation`) — committing it changes nothing but the
newline. Tab still commits. Unit test in the completion tests; drive in tmux
(type `SELECT * FROM sys.tables`, Enter → new line). Record the decision in
`docs/decisions.md`.

## F6 — `fileutil.WithLock` is unfair under contention

**Where:** `internal/fileutil/lock.go` (`lockPoll` fixed at 5 ms, `lockWait`
2 s). Two tests were loosened rather than fixing it (the deleted
Windows findings doc, § D).

**What:** every waiter polls on the same fixed beat, so on slow disks (two
fsyncs per hold) one waiter can lose every race and hit `lockWait`; in the
field, a Save that reports "locked by another gossms instance" while
another instance is merely busy.

**Plan:** jittered, growing poll (5 ms doubling to ~50 ms, ±50 % jitter from
`math/rand/v2`) so waiters desynchronise; keep `lockWait` as the bound (exit
time, `internal/tui/app_saves.go`). Then restore the two loosened tests
(`TestWithLockSerializesReadModifyWrite`'s raised `lockWait`,
`TestAppendRotationLosesNothing`'s retry) and run them on win10cli with
`scripts/wintest.sh test -count=5 ./internal/fileutil/ ./internal/config/
./internal/cli/audit/`. If they still starve, a ticket file (FIFO order) is
the next step — not before.

## F7 — a catalog name holding a control character is offered as-is

**Where:** completion catalog candidates. `docs/open-threads.md` §
Completion.

**What:** `[weird⏎name]` is offered; its popup label draws as `weirdname`;
a CR in a name is lost to the editor's CRLF normalisation, so that insert
names a different object.

**Plan (proposed decision):** skip any name holding a C0 control character
(or DEL) from the candidates — it cannot be offered faithfully, and typing
it by hand still works. Unit test; record in `docs/decisions.md`; delete the
open-threads bullet.
